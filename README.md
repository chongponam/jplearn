# 오늘의 단어 (今日の単語)

매일 일본어 단어 8개를 카드로 익히고 퀴즈로 확인하는 웹 단어장입니다.

- JLPT N5 · N4 · N3 단어 108개, 급수 선택 가능
- 카드 뒤집기로 읽는 법 · 뜻 · 예문 확인
- 단어 · 예문 발음 듣기 (브라우저 음성 읽기)
- 4지선다 뜻 맞히기 퀴즈
- 외운 단어와 연속 학습일 기록 (브라우저에 저장)

## GitHub Pages로 배포하기

1. GitHub에서 새 저장소를 만듭니다 (예: `jp-tango`, Public).
2. `index.html`과 `README.md`를 저장소에 올립니다.
   - 웹에서: **Add file → Upload files** 로 두 파일을 끌어다 놓고 **Commit changes**
3. 저장소의 **Settings → Pages** 로 이동합니다.
4. **Source**를 `Deploy from a branch`, 브랜치를 `main` / `/ (root)`로 선택하고 **Save**.
5. 1~2분 뒤 `https://<내 아이디>.github.io/jp-tango/` 에서 열립니다.

## 휴대폰 홈 화면에 추가

- 아이폰(Safari): 공유 버튼 → **홈 화면에 추가**
- 안드로이드(Chrome): 메뉴 ⋮ → **홈 화면에 추가**

## 단어 추가하기

`index.html` 안의 `const W=[ ... ]` 목록에 아래 형식으로 한 줄씩 추가하면 됩니다.

```js
["単語","たんご","단어","単語を覚える。","단어를 외운다.","N3"],
```

순서: 표기, 읽기, 뜻, 일본어 예문, 한국어 해석, 급수(N5/N4/N3)

- 학습 기록은 각 기기의 브라우저에 저장되므로 기기끼리 공유되지 않습니다.
- 발음이 나오지 않으면 아이폰은 무음 모드를 끄고, 윈도우는 설정에서 일본어 음성 팩을 설치하세요.
